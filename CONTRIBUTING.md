# 🤝 Contributing

Thanks for your interest in contributing to this NLP project!

---

## 🛠️ How to Contribute

1. **Fork** the repository
2. **Clone** your fork locally:
```bash
   git clone https://github.com/your-username/Disneyland-Review-Sentiment-Analysis-using-NLP.git
```
3. **Create a branch** for your feature:
```bash
   git checkout -b feature/your-feature-name
```
4. **Make your changes** and commit:
```bash
   git commit -m "feat: describe your change"
```
5. **Push** and open a Pull Request

---

## 💡 Ideas for Contributions

- Try alternative models (SVM, Naive Bayes, BERT)
- Add a Streamlit or Flask web app for live predictions
- Improve visualisations (word clouds, sentiment over time)
- Extend to more Disneyland parks or languages
- Add unit tests for the preprocessing pipeline

---

## 📐 Code Style

- Follow PEP 8 for Python code
- Use meaningful variable names
- Add docstrings to all functions
- Keep notebooks clean — clear all outputs before committing
